# TLC Vault

TLC Vault is a private code workspace built for students who practice programming on their personal computers but often need access to that code later on shared college computers.

The idea is simple:

> Keep your important practice code in one private place, organized into repositories and code files, so you can access, edit, copy and manage it whenever you need it.

TLC Vault is designed to be lightweight and easy to use. It is not intended to replace GitHub or become a full version-control platform. It is mainly a personal workspace for storing and accessing programming practice.

---

## Why TLC Vault?

In many college labs, students cannot freely use their personal laptops or phones. This creates a simple but annoying problem.

You may have written a program at home, but when you reach the college lab you may not have that code with you.

You could use:

- Google Drive
- GitHub
- cloud storage
- messaging apps
- USB drives

But these are not always convenient on shared college systems, especially when you don't want to log into your personal accounts on a lab computer.

TLC Vault provides a small private workspace specifically for this use case.

A student can:

1. Create an account.
2. Create a repository.
3. Add code files.
4. Store their code.
5. Open the code later from another computer.
6. Edit and save it.
7. Copy the code whenever required.
